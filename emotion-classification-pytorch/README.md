# Emotion Classification with Attention (PyTorch + FastAPI + Gradio)

End-to-end deep learning project for 6-class emotion classification (`sadness`, `joy`, `love`, `anger`, `fear`, `surprise`) built purely with **PyTorch**, featuring model comparison, attention visualization, and a production-ready **FastAPI + Gradio** deployment service.
## Kaggle Notebook & Dataset
- **Full Training Notebook:** [View & Run on Kaggle][YOUR_KAGGLE_NOTEBOOK_URL](https://www.kaggle.com/code/mohamedelneel/emotion-classification-with-attention/edit)]
- **Dataset Used:** [Emotions Dataset for NLP](https://kaggle.com)

## Model Comparison (Test Set)

Four architectures were trained and evaluated on the same held-out test set:

| Model | Backend | Accuracy | Macro F1 | Weighted F1 | Parameters | Latency |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **Transformer (Small BERT)** | `transformer` | **93.05%** | **0.8955** | **0.9308** | 28.77M | 3.74 ms |
| **BiLSTM + Attention** | `recurrent` | 91.65% | 0.8828 | 0.9192 | 1.27M | 2.01 ms |
| **LSTM** | `recurrent` | 91.95% | 0.8817 | 0.9218 | 1.13M | 1.47 ms |
| **GRU** | `recurrent` | 91.60% | 0.8740 | 0.9187 | 1.10M | 1.40 ms |

## Features
- **Single Framework**: Pure PyTorch implementation (avoids TensorFlow/PyTorch conflicts).
- **Explainability**: Bahdanau-style Additive Attention heatmaps for BiLSTM predictions.
- **Shared Codebase**: Training and serving share exact preprocessing and model definitions (`app/common.py`, `app/models.py`).
- **Production API & UI**: REST API powered by FastAPI with Pydantic validation, paired with an interactive Gradio web interface mounted at `/ui`.

## Quick Start (Local)

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Place your trained artifacts** inside the `artifacts/` directory (generated by running the notebook).

3. **Run the server:**
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
   - **Gradio Web UI**: `http://localhost:8000/ui`
   - **Swagger API Docs**: `http://localhost:8000/docs`

## Run with Docker

```bash
docker build -t emotion-api .
docker run -p 8000:8000 emotion-api
```

## API Usage Example

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "i feel so happy and grateful today"}'
```

## Environment Variables

| Variable | Default | Description |
| :--- | :--- | :--- |
| `ARTIFACTS_DIR` | `./artifacts` | Directory containing `model_info.json` and model weights |
| `MAX_TEXT_CHARS` | `1000` | Maximum allowed characters per input text |
| `MAX_BATCH_SIZE` | `64` | Maximum texts allowed per batch request |
